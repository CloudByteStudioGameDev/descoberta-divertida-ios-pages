Política de privacidade — Descoberta Divertida para iOS

Atualizada em 14 de outubro de 2026.

Esta política se aplica à versão para iOS de Descoberta Divertida, publicada pela Cloud Byte Studio.

Dados do jogo

O jogo não exige cadastro nem acesso a uma conta. O progresso e as preferências ficam armazenados no próprio dispositivo. A Cloud Byte Studio não recebe esses dados por meio do jogo.

Esta versão iOS não inclui anúncios nem serviços próprios de análise de uso. O jogo não coleta dados pessoais nem os compartilha com a Cloud Byte Studio ou parceiros por meio de seu funcionamento.

Links externos e App Store

O jogo pode abrir a página da Cloud Byte Studio no Instagram se o usuário escolher esse link. Nesse caso, o serviço externo aplica suas próprias práticas de privacidade. A Apple administra a App Store, inclusive o download e a compra do app, conforme as políticas da Apple.

Crianças e famílias

O jogo é destinado ao público familiar. Não solicitamos dados pessoais de crianças por meio do jogo.

Exclusão e contato

Para remover os dados de progresso armazenados localmente, use a opção de redefinir o progresso no jogo ou desinstale o app. Para dúvidas de privacidade, escreva para cloudbytestudio@gmail.com.

Esta política pode ser atualizada caso as funções ou as práticas de dados do app mudem.
